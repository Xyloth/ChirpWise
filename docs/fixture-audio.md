# Fixture Audio

The initial dataset uses generated WAV clips. They are not real bird recordings and should not be used for learning field identification.

The fixture clips exist so the app can be evaluated immediately:

- audio playback
- quiz flow
- progress tracking
- waveform rendering
- attribution display
- coverage reporting

Generated fixture audio is marked as:

```text
source = fixture
license_name = CC0-1.0
recordist = Bird Sound Trainer
```

Replace it with Xeno-canto or another properly licensed source before using the trainer as a real study product.
